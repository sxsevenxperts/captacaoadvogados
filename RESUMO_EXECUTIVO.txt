═ CRIAR PRIMEIRO USUÁRIO ADMINISTRADOR ══════════════════════════════════════════════

PASSO 1: Criar usuário no Supabase Auth
────────────────────────────────────────────────────────────────────────────────
1. Supabase Dashboard
2. Authentication → Users
3. Clique "Add user"
4. Email: seu-email@example.com
5. Password: escolha uma senha
6. Copie o UUID do usuário criado (clique no usuário, copie o ID)

PASSO 2: Inserir na tabela admins
────────────────────────────────────────────────────────────────────────────────
1. Supabase Dashboard
2. SQL Editor → New Query
3. Execute:

INSERT INTO admins (id, email, nome, role)
VALUES (
  'uuid-que-voce-copiou-acima',
  'seu-email@example.com',
  'Seu Nome',
  'admin'
);

PASSO 3: Testar
────────────────────────────────────────────────────────────────────────────────
1. npm run dev (se não estiver rodando)
2. Acesse http://localhost:3000/admin/login
3. Email: seu-email@example.com
4. Password: a senha que criou
5. Deve redirecionar para /admin/diagnosticos

═ PASSO A PASSO PARA PRODUÇÃO ═══════════════════════════════════════════════════

PASSO 1: Build local
────────────────────────────────────────────────────────────────────────────────
$ npm run build

Se houver erros: não proceda. Se tudo OK, continua.

PASSO 2: Deploy (exemplo com Vercel)
────────────────────────────────────────────────────────────────────────────────
1. Empurar código para GitHub:
   $ git add .
   $ git commit -m "Initial setup"
   $ git push

2. Vercel.com → New Project
3. Selecione seu repositório do GitHub
4. Clique "Import"
5. Environment Variables:
   NEXT_PUBLIC_SUPABASE_URL = https://seu-projeto.supabase.co
   NEXT_PUBLIC_SUPABASE_ANON_KEY = sua-chave-anonima
6. Deploy

PASSO 3: Configurar CORS no Supabase
────────────────────────────────────────────────────────────────────────────────
1. Supabase Dashboard
2. Settings → API
3. "Authorized redirect URLs"
4. Adicione:
   https://seu-dominio-vercel.vercel.app/admin/login

PASSO 4: Testar em produção
────────────────────────────────────────────────────────────────────────────────
1. Acesse seu domínio
2. Form de diagnóstico deve funcionar
3. Admin login deve funcionar
4. Dashboard deve carregar diagnósticos
